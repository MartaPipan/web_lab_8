#  Конвертер тексту у стилі Ransom Note (Записка з вирізаних літер)

Це інтерактивний проект для **конвертації тексту** у стилі колажу (де кожна літера ніби вирізана з газет та журналів). Конвертер перетворює будь-який введений користувачем текст на динамічну колірну композицію зі збережених зображень, літер, цифр та персоналізованих символів із плавною анімацією послідовного падіння літер.

---

## Головні функції (Main Features)

1. **Конвертація символів**:
   - **ВЕЛИКІ ЛІТЕРИ**: Програма шукає оригінальні файли у верхньому регістрі (наприклад, `A.png`).
   - **Малі літери**: Використовує файли з префіксом `small_` (наприклад, `small_a.png`).
   - **Цифри (0-9)**: Використовує файли з префіксом `number_` (наприклад, `number_1.png`).
   - **Спеціальні знаки**: Підтримує 10 унікальних символів, які автоматично конвертуються у безпечні текстові назви файлів на диску (наприклад, `!` перетворюється на шлях до `symbol_exclamation.png`).

2. **Захист від пустки (Автоматичний Fallback та План Б)**:
   - Якщо введеного символу або літери **взагалі немає** у колекції зображень (наприклад, `#`, `$`), система автоматично відобразить його як звичайний текст із клавіатури, зберігши великий масштаб та анімацію появи.
   - Скрипт має додатковий захист через `img.onerror`: якщо якийсь підтримуваний файл випадково видалено з диска (наприклад, зникла буква `A.png`), він миттєво підміниться текстом у реальному часі, рятуючи екран від порожніх зламаних квадратів.

3. **Автоматичне перенесення рядків (Word-Wrap)**:
   - Елементи зображень використовують властивість `display: inline-block`, а пробіли генеруються як текстові блоки зі стилем `white-space: normal`. Це дозволяє браузеру переносити довгий текст автоматично і виключно в місцях пробілів.

4. **Автоматичне зникнення тексту за таймером**:
   - Рівно через **60 секунд** після натискання кнопки конвертації весь введений текст та згенеровані літери автоматично зникають з екрану з міркувань конфіденційності, очищаючи поля та повертаючи курсор у вікно вводу.

## Використані технології (Built With)

- **HTML5**: Семантична структура з полем `textarea`, інтегрованою кнопкою та динамічною зоною результату.
- **CSS3 (Custom Properties & Keyframes)**:
  - Анімація `@keyframes appears` для ефекту падіння/появи літер.
  - Використання CSS-змінних (`--anim-delay` та `--shift`) для створення послідовної затримки появи літер та випадкового аналогового зсуву по вертикалі (`randomShift`).
- **JavaScript (ES6+)**:
  - Динамічна маніпуляція DOM-елементами (`document.createElement`).
  - Регулярні вирази (`RegExp`) для фільтрації та розпізнавання типів символів.
  - Екранування символів (наприклад, `\/`) для безпечної роботи лапок та слішу всередині регулярних виразів.
  - Таймери (`setTimeout` та `clearTimeout`) для автоматичного очищення екрану через 60 секунд.

## Покроковий розбір роботи коду JavaScript (Step-by-Step Code Explanation)

### Крок 1: Ініціалізація та очищення екрану

```javascript
const text = sourceTextArea.value;
resultContainer.innerHTML = "";
if (countdownTimeout) {
    clearTimeout(countdownTimeout);
}
```

- **Що відбувається:** Скрипт зчитує весь текст із поля введення (`textarea`) і повністю очищає білий папір результату (`resultContainer`).
- **Навіщо це потрібно:** Це повністю видаляє попередню згенеровану записку. Також команда `clearTimeout` скидає старий таймер на 60 секунд, щоб відлік часу для нового тексту розпочався заново з моменту останнього кліку.

---

### Крок 2: Ефект покрокового падіння літер (Черговість анімації)

```javascript
let letterCount = 0;
// ... всередині циклу:
const animDelay = letterCount * 0.08 + "s";
```

- **Що відбувається:** Код використовує лічильник `letterCount` та множить його на `0.04` секунди для кожного наступного елемента.
- **Навіщо це потрібно:** Це створює затримку появи. Завдяки цьому літери не з'являються всі одночасно, а візуально «падають» на папір по черзі, одна за одною, створюючи реалістичний ефект друку або викладання записки.

---

### Крок 3: Обробка пробілу та примусового Enter

```javascript
if (char === " ") {
    const space = document.createElement("span");
    space.innerHTML = " ";
    space.style.display = "inline";
    space.style.whiteSpace = "normal";
    resultContainer.appendChild(space);
} else if (char === "\n") {
    const br = document.createElement("br");
    resultContainer.appendChild(br);
}
```

- **Що відбувається:** При зустрічі пробілу створюється текстовий елемент зі стилем `whiteSpace = "normal"`. При зустрічі знаку перенесення рядка (`\n`) створюється фізичний тег `<br>`.
- **Навіщо це потрібно:** Стиль `normal` дозволяє браузеру автоматично переносити текст на нову лінію, але виключно в місцях пробілів між словами (слова ніколи не розриваються по літерах). Тег `<br>` обробляє натискання клавіші Enter, щоб користувач міг самостійно створювати абзаци.

---

### Крок 4: Повна активація символів та пряме додавання в DOM

```javascript
const hasSymbol = /[!\.\-_,\?\@\":\/]/.test(char);
// ...
img.style.setProperty("--anim-delay", animDelay);
img.style.setProperty("--shift", randomShift);
resultContainer.appendChild(img);
```

- **Що відбувається:** Завдяки регулярному виразу зображення додаються безпосередньо в `resultContainer`.
- **Навіщо це потрібно:** Пряме додавання зображень у контейнер (`resultContainer.appendChild(img)`) відновлює правильну ієрархію елементів для оригінального файлу `style.css`. Тепер селектор `>img` знову бачить картинки, а передані в JavaScript змінні `--anim-delay` (черга появи) та `--shift` (випадковий стрибок літери від -10px до +30px)

### Крок 5: Фільтрація та перевірка наявності картинок у колекції

```javascript
const hasNumber = /[0-9]/.test(char);
const hasLetter = /[a-zA-Z]/.test(char);
const hasSymbol = /[!\.\-_,\?\@\":\/]/.test(char);

if (hasNumber || hasLetter || hasSymbol) {
```

- **Що відбувається:** Програма заздалегідь розділяє символи на три категорії за допомогою регулярних виразів: чи це цифра (`0-9`), чи це англійська літера (`a-z`), чи це один із 10 підтримуваних спеціальних знаків (включаючи лапки `"`, двокрапку `:` та косу риску `/`).
- **Навіщо це потрібно:** Якщо символ відповідає одній із цих груп, запускається процес генерації картинки `<img>`. Якщо символ сторонній (наприклад, `#` або `$`), програма навіть не шукає файл, а одразу переходить до Кроку 7 (малює текстом), щоб захистити екран від порожнечі.

---

### Крок 6: Підбір правильного файлу та ефекти зсуву

```javascript
if (hasNumber) {
  img.src = `${Letters}number_${char}.png`;
} else if (hasSymbol) {
  // ... логіка підбору імені символу за словником
  img.src = `${Letters}symbol_${symbolName}.png`;
} else if (char === char.toUpperCase()) {
  img.src = `${Letters}${char}.png`;
} else {
  img.src = `${Letters}small_${char}.png`;
}
```

- **Що відбувається:** Код збирає правильний шлях до файлу: додає префікс `number_` для цифр, перекладає знаки за текстовим словником для префікса `symbol_`, додає `small_` для малих літер або завантажує чисту велику літеру. Також він додає випадковий вертикальний зсув через CSS-змінну `--shift` (від `-10px` до `+30px`) та черговість анімації появи.
- **Навіщо це потрібно:** Це забезпечує точний збіг назв символів із файлами на вашому диску, а випадковий зсув створює реалістичний ефект недбалої ручної склейки журналу.

---

### Крок 7: Захист від помилки (План Б)

```javascript
img.onerror = function () {
  const textFallback = document.createElement("span");
  textFallback.innerText = char;
  textFallback.style.setProperty("--anim-delay", animDelay);
  if (this.parentNode) {
    this.parentNode.replaceChild(textFallback, this);
  }
};
```

- **Що відбувається:** Якщо ви ввели правильний символ, який є в колекції (наприклад, букву `A`), але файл `A.png` випадково видалили з комп'ютера або перейменували, браузер дасть помилку завантаження картини. Функція `img.onerror` миттєво ловить цей збіг і замінює поламаний тег картинки на великий текстовий символ.
- **Навіщо це потрібно:** Це  захист від появи порожніх квадратів на екрані, якщо файли на диску пошкоджено.

---

### Чому потрібні ОБИДВА блоки (Різниця між Кроком 7 та Кроком 8)

Ці два блоки працюють у різні моменти часу: один перевіряє теорію на клавіатурі, а інший — наявність файлу на диску.

- **Крок 8 (`else`)** — працює **одразу (в момент друку)**: Обробляє символи, яких взагалі ніколи не було у колекції. Скрипт навіть не намагається шукати файл. (Приклад: користувач ввів знак `%` або `#`. Програма одразу малює їх текстом).
- **Крок 7 (`img.onerror`)** — працює **пізніше (в момент завантаження)**: Спрацьовує, якщо символ має бути в колекції, але файлу фізично немає на диску (видалений, перейменований або пошкоджений). (Приклад: користувач ввів букву `b`. Код створив шлях `small_b.png`. Але випадково стерли цей файл із папки `images/`. Завдяки `onerror` замість порожнього квадрата з'явиться текстова буква `b`).

---

### Крок 8: Текст із клавіатури для невідомих символів

```javascript
else {
  const textSpan = document.createElement("span");
  textSpan.innerText = char;
  textSpan.style.setProperty("--anim-delay", animDelay);
  resultContainer.appendChild(textSpan);
}
```

- **Що відбувається:** Цей блок спрацьовує для знаків, яких ніколи не було у колекції (наприклад, `%`, `*`, `&`). Програма просто малює їх оригінальним текстом безпосередньо в `resultContainer`.
- **Навіщо це потрібно:** Це гарантує, що конвертер зможе відобразити 100% символів з будь-якої мови, автоматично підлаштовуючи їх під великий масштаб паперу та загальну чергу анімації.

---

### Крок 9: Автоматичний таймер знищення

```javascript
countdownTimeout = setTimeout(function () {
  sourceTextArea.value = "";
  resultContainer.innerHTML = "";
  sourceTextArea.focus();
}, 60000);
```

- **Що відбувається:** Після повного завершення перебору всього тексту запускається невидимий таймер на 60 000 мілісекунд (1 хвилина) з моменту натискання кнопки. Через 60 секунд функція повністю стирає текст з поля введення, очищає папір результату та автоматично повертає курсор у поле для нової записки.
- **Навіщо це потрібно:** Це функція безпеки, яка гарантує, що конфіденційний згенерований текст не залишиться на екрані комп'ютера без нагляду.

## Документація JSDoc (@param, @type, @returns)

Для підтримки чистоти та професійної підсвітки коду в редакторі (VS Code) використовуються такі теги документування:

- **`@param {MouseEvent} event`** — Описує об'єкт події кліку миші, який автоматично передається браузером у функцію при натисканні кнопки "Convert".
- **`@param {Event} errEvent`** — Описує об'єкт події помилки (`onerror`). Він допомагає браузеру зрозуміти контекст, якщо якась картинка не завантажилася.
- **`@this {HTMLImageElement}`** — Вказує редактору (VS Code), що всередині функції `img.onerror` ключове слово `this` посилається саме на те зображення, яке дало збій. Це дозволяє безпечно викликати метод `this.parentNode` для заміни елемента.
- **`@type {string}` та `@type {number|null}`** — Чітко визначають типи даних для змінних, щоб захистити код від випадкових помилок розробника (наприклад, спроби записати текст у змінну таймера).
- **`@returns {void}`** — Показує, що ці функції виконують дії на сторінці (маніпулюють DOM), але не повертають жодного математичного чи логічного значення назад через оператор `return`.
