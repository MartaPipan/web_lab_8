# 📑 Конвертер тексту у стилі Ransom Note (Записка з вирізаних літер)

Це інтерактивний веб-проект для **конвертації тексту** у стилі колажу (де кожна літера ніби вирізана з газет та журналів). Конвертер перетворює будь-який введений користувачем текст на динамічну колірну композицію зі збережених зображень, літер, цифр та персоналізованих символів із плавною анімацією та розумним перенесенням слів.

---

## Головні функції (Main Features)

1. **Розумна символів**:
   - **ВЕЛИКІ ЛІТЕРИ**: Програма шукає оригінальні файли у верхньому регістрі (наприклад, `A.png`).
   - **Малі літери**: Використовує файли з префіксом `small_` (наприклад, `small_a.png`).
   - **Цифри (0-9)**: Використовує файли з префіксом `number_` (наприклад, `number_1.png`).
   - **Спеціальні знаки**: Підтримує 10 унікальних символів, які автоматично конвертуються у безпечні текстові назви файлів на диску (наприклад, `!` перетворюється на шлях до `symbol_exclamation.png`).

2. **Захист від пустки (Автоматичний Fallback)**:
   - Якщо введеного символу або літери **немає** у колекції зображень (наприклад, `#`, `$`), система автоматично відобразить його як звичайний текст із клавіатури, зберігши великий масштаб та анімацію появи.
   - Скрипт має захист через `img.onerror`: якщо якийсь файл випадково видалено з диска, він миттєво підміниться текстом у реальному часі.

3. **перенесення рядків (Word-Wrap)**:
   - Літери всередині слів ніколи не відриваються одна від одної! Кожне слово інкапсулюється в окремий захищений блок (`inline-block`).
   - Автоматичне перенесення рядків браузером відбувається **виключно в місцях пробілів**, що гарантує перенесення слів лише цілком.

4. **Автоматичне зникнення тексту за таймером**:
   - Рівно через **60 секунд** після натискання кнопки конвертації весь введений текст та згенеровані літери автоматично зникають з екрану з міркувань конфіденційності, очищаючи поля та повертаючи курсор у вікно вводу.

## Використані технології (Built With)

- **HTML5**: Семантична структура з полем `textarea`, інтегрованою кнопкою та динамічною зоною результату.
- **CSS3 (Custom Properties & Keyframes)**:
  - Анімація `@keyframes appears` для ефекту падіння/появи літер.
  - Використання CSS-змінних (`--anim-delay` та `--shift`) для створення послідовної затримки появи літер та випадкового аналогового зсуву по вертикалі (`randomShift`).
- **JavaScript (ES6+)**:
  - Динамічна маніпуляція DOM-елементами (`document.createElement`).
  - Регулярні вирази (`RegExp`) для фільтрації та розпізнавання типів символів.
  - Таймери (`setTimeout` та `clearTimeout`) для автоматичного очищення екрану через 60 секунд.

## Покрокове пояснення логіки коду (JS Steps)

1. **Початкове очищення**: При натисканні на кнопку _Convert_ скрипт повністю видаляє старий результат та анулює будь-який активний таймер зворотного відліку, запущений попереднім кліком (`clearTimeout`).
2. **Збирання слів**: Текст читається символ за символом. Код групує літери всередині невидимого тегу `span` зі стилем `display: inline-block`. Це змушує браузер сприймати слово як єдиний неподільний об'єкт.
3. **Сортування картинок за умовами (`if/else`)**:
   - Якщо це цифра, додається префікс `number_`.
   - Якщо це один із 10 символів, він перекладається у текстове ім'я (наприклад, `?` стає `question`) і посилається на файл `symbol_question.png`.
   - Якщо це літера, перевіряється її регістр (велика/мала) для формування точного шляху.
4. **Обчислення CSS**: JavaScript вираховує затримку для кожної наступної літери (`letterCount * 0.04s`), щоб вони падали на папір по черзі, а також генерує випадкове вертикальне зміщення від `-10px` до `+20px` через змінну `--shift` для створення ефекту недбалої ручної склейки.
5. **Повний захист від збоїв**: Якщо символ не розпізнано (наприклад, `%`), він миттєво переходить у блок генерації звичайного тексту, що гарантує відсутність порожніх дірок у фінальному реченні.

## 📘 Покроковий розбір роботи коду JavaScript (Step-by-Step Code Explanation)

### Крок 1: Ініціалізація та очищення екрану

```javascript
const text = sourceTextArea.value;
resultContainer.innerHTML = '';
if (countdownTimeout) {
    clearTimeout(countdownTimeout);
}
```

- **Що відбувається:** Скрипт зчитує весь текст із поля введення (`textarea`) і повністю очищає білий папір результату (`resultContainer`).
- **Навіщо це потрібно:** Це видаляє попередню згенеровану записку. Також команда `clearTimeout` скидає старий таймер на 60 секунд, щоб відлік часу для нового тексту почався спочатку.

---

### Крок 2: Створення контейнера для слова (Захист від розриву слів)

```javascript
let currentWordSpan = document.createElement('span');
currentWordSpan.style.display = 'inline-block';
currentWordSpan.style.whiteSpace = 'nowrap';
```

- **Що відбувається:** Перед початком аналізу літер створюється перший невидимий тег `<span>` для першого слова. Йому примусово задаються стилі `display: inline-block` та `whiteSpace = 'nowrap'`.
- **Навіщо це потрібно:** Це найважливіша логіка для красивого перенесення тексту. Вона забороняє браузеру розривати літери всередині слова. Браузер бачить цей контейнер як один суцільний об'єкт (цеглинку).

---

### Крок 3: Обробка пробілу

```javascript
if (char === ' ') {
    if (currentWordSpan.children.length > 0) {
        resultContainer.appendChild(currentWordSpan);
    }
    const space = document.createElement('span');
    space.innerHTML = ' ';
    space.style.display = 'inline';
    space.style.whiteSpace = 'normal';
    resultContainer.appendChild(space);
```

- **Що відбувається:** Коли код зустрічає пробіл, він бере все накопичене слово (`currentWordSpan`) і виштовхує його на екран. Потім створює особливий пробіл зі стилем `whiteSpace = 'normal'`.
- **Навіщо це потрібно:** Стиль `normal` дозволяє браузеру робити автоматичне перенесення рядка (`<br>`) на нову лінію **тільки в місцях пробілів**. Слово після пробілу перенесеться на новий рядок повністю, якщо воно не поміщається. Після цього створюється новий порожній `<span>` для наступного слова.

### Крок 4: Обробка примусового перенесення рядка (Кнопка Enter)

```javascript
} else if (char === '\n') {
    if (currentWordSpan.children.length > 0) {
        resultContainer.appendChild(currentWordSpan);
    }
```

- **Що відбувається:** Якщо користувач натиснув Enter у полі введення, код бачить символ `\n`. Він публікує поточне слово на екран і фізично ставить тег `<br>` на папір результату.
- **Навіщо це потрібно:** Це дозволяє користувачеві самостійно вирішувати, де робити абзаци та нові рядки.

### Крок 5: Фільтрація та перевірка наявності картинок у колекції

```javascript
const hasNumber = /[0-9]/.test(char);
const hasLetter = /[a-zA-Z]/.test(char);
const hasYourSymbol = /[!\.\-_,\?\@\:]/.test(char) || char === '"' || char === '/';

if (hasNumber || hasLetter || hasYourSymbol) {
```

- **Що відбувається:** Програма заздалегідь розділяє символи на три категорії за допомогою регулярних виразів: чи це цифра (`0-9`), чи це англійська літера (`a-z`), чи це один із ваших 10 створених символів.
- **Навіщо це потрібно:** Якщо символ відповідає одній із цих груп, запускається процес генерації картинки `<img>`. Якщо символ сторонній (наприклад, `#` або `$`), програма навіть не шукає файл, а одразу переходить до Кроку 7 (малює текстом), щоб захистити екран від порожнечі.

---

### Крок 6: Підбір правильного файлу та ефекти зсуву

```javascript
if (hasNumber) img.src = `${Letters}number_${char}.png`;
else if (hasYourSymbol) { ... img.src = `${Letters}symbol_${symbolName}.png`; }
else if (char === char.toUpperCase()) img.src = `${Letters}${char}.png`;
else img.src = `${Letters}small_${char}.png`;
```

- **Що відбувається:** Код збирає правильний шлях до файлу (додає `number_` для цифр, `symbol_` зі словом для знаків, `small_` для малих літер або бере чисту велику літеру). Також він додає випадковий вертикальний зсув через CSS-змінну `--shift` (від -10px до +20px).
- **Навіщо це потрібно:** Це забезпечує точний збіг назв символів із файлами на вашому диску, а випадковий зсув створює реалістичний ефект недбалої ручної склейки журналу.

---

### Крок 7: Захист від людської помилки (План Б)

```javascript
img.onerror = function() {
    const textFallback = document.createElement('span');
    textFallback.innerText = char;
    if (this.parentNode) {
        this.parentNode.replaceChild(textFallback, this);
    }
};
```

- **Що відбувається:** Якщо ввели правильний символ (наприклад, букву `A`), але файл `A.png` випадково видалили з комп'ютера або перейменували, браузер дасть помилку завантаження картини. Функція `img.onerror` миттєво ловить цей збіг і замінює поламаний тег картинки на великий текстовий символ.
- **Навіщо це потрібно:** Це захист від появи порожніх "квадратів із хрестиками" на екрані, якщо файли на диску пошкоджено.

### Чому потрібні ОБИДВА блоки (Різниця між Кроком 6 та Кроком 7)

Ці два блоки працюють у різні моменти часу: один перевіряє теорію на клавіатурі, а інший — на диску.
Крок 7 захищає від символів, яких немає в коді. Крок 6 (img.onerror) захищає від помилки — якщо хтось випадково видалить файл картинки з комп'ютера.

Приклад
Крок 7 (else) Одразу (в момент друку) Обробляє символи, яких взагалі ніколи не було у колекції. Скрипт навіть не намагається шукати файл. Користувач ввів знак % або #. Програма одразу малює їх текстом.
Крок 6 (img.onerror) Пізніше (в момент завантаження) Це "план Б" (страховка). Спрацьовує, якщо символ має бути в колекції, але файлу фізично немає на диску (видалений, перейменований, пошкоджений). Користувач ввів букву b. Код створив шлях small_b.png. Але випадково стерли цей файл із папки images/. Завдяки onerror замість порожнього квадрата з'явиться текстова буква b.

### Крок 9: Публікація останнього слова та таймер знищення

```javascript
if (currentWordSpan.children.length > 0) {
    resultContainer.appendChild(currentWordSpan);
}
countdownTimeout = setTimeout(function() { ... }, 60000);
```

- **Що відбувається:** Після завершення перебору всього тексту код виводить на екран останнє слово речення (після якого користувач не ставив пробіл). Потім запускається невидимий таймер на 60 000 мілісекунд (1 хвилина). Через 60 секунд функція повністю стирає текст з поля та паперу.

### @param @type @returns

• @param {MouseEvent} event: Описує об'єкт події кліку миші, який автоматично передається браузером у функцію при натисканні кнопки "Convert".
• @param {Event} errEvent: Описує об'єкт події помилки (onerror). Він допомагає браузеру зрозуміти контекст, якщо якась картинка не завантажилася.
• @this {HTMLImageElement}: Вказує середовищу розробки (VS Code), що всередині функції img.onerror ключове слово this посилається саме на те зламане зображення, яке дало збій, дозволяючи безпечно викликати метод this.parentNode.
• @type {string} та @type {number|null}: Чітко визначають типи даних для змінних, щоб захистити код від випадкового присвоєння неправильного типу (наприклад, спроби записати текст у таймер).
• @returns {void}: Показує, що ці функції виконують дії на сторінці, але не повертають жодного значення (результату математичних обчислень тощо) назад через оператор return.
